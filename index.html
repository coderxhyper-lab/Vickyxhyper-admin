Key Expiry Alerts

Live countdowns for keys expiring in the next 7 days, plus keys already expired. Alerts follow the warning points set in Settings (24h · 12h · 1h).

Free Plan Cooldown Rule

Free keys include 5 searches. When the free quota is exhausted, a 24-hour cooldown starts automatically; when it completes, the same 5 searches are restored. Paid keys use their own daily and total limits. The remaining cooldown time is shown live to the user until the searches return.

Generate Access Key

Keys are generated in the HYPERXVICKY-XXXX-XXXX-XXXX format as secure unique codes, or as a custom HYPERXVICKY- key where permitted. Duration, limits and value are stored with the key: created time, duration value and unit, and the exact expiry time.
Moderator limits apply: User keys only, maximum duration 1 month, no Lifetime keys. These limits apply to every key a Moderator generates.
The HYPERXVICKY- prefix is added automatically if you leave it out. Must be unique — rejected if it already exists.
Exact rule: 5 Minutes = exactly 5 minutes after creation, 2 Hours = exactly 2 hours, 7 Days = exactly 7 days. Lifetime has no expiry.
